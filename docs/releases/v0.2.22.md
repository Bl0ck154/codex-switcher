# Codex Switcher v0.2.22

This release updates account handling, quota monitoring and the remote dashboard.

## Changes

- **Re-login from an account card.** Renew a ChatGPT login after a 401 or invalid-token error without deleting the saved account. The app checks that the user and workspace match and keeps the account name and preferences.
- **Optional automatic account switching.** In Settings, enable switching when the active ChatGPT account has confirmed exhausted quota and another saved account has available capacity. This is **off by default**. The app rechecks the active account before changing it.
- **Safer OAuth credentials.** Protect rotated refresh tokens from stale `auth.json` snapshots, refresh JWT access tokens before expiry and serialize account switching and token refresh across processes.
- **Codex CLI daemon handling.** Stop the managed CLI daemon on account changes so a new session does not retain the previous account's credentials.
- **More reliable usage requests.** Reduce concurrent usage fetches and pace retry behavior to mitigate transient Cloudflare 403 responses.
- **Remote dashboard authentication.** Require a secret for non-loopback access, protect command endpoints and default to localhost.
- **UI and maintenance.** Add a Check for Updates action in Settings, improve long account-name layout and sync the upstream MIT license.

## Important notes

- Auto-switching can close and reopen Codex desktop. Unsaved work may be lost, especially when force-close is enabled. Leave it disabled unless you want this behavior.
- Remote dashboard access needs the configured secret. Use TLS or a secure tunnel for remote connections.
- macOS installers are not Apple-notarized.
- Automated tests cover quota decisions and credential handling. Automatic switching after a real newly exhausted quota has not yet been observed end to end.
